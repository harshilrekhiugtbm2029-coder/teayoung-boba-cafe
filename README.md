# TeaYoung Boba Café

A responsive website for **TeaYoung Boba Tea** and its two Noida locations. The experience is designed as a warm digital front door for a neighbourhood café: it introduces the brand, presents verified drinks and Korean ramyun items, showcases owner-approved photography, makes both locations easy to find, and gives visitors direct phone and WhatsApp contact options.

## Design direction

The site uses a late-afternoon café editorial style with espresso, guava coral, mint, cream, and warm yellow. Playfair Display gives the brand an expressive display voice, while DM Sans and DM Mono keep body copy and small interface labels clear. Motion is intentionally restrained: a floating hero cup, a slow ticker, small menu transitions, and responsive button feedback.

## Stack

React, TypeScript, Vite, Tailwind CSS, Lucide icons, and custom CSS. This is a static frontend build with no backend, database, or external API key requirements.

## Run locally

```bash
pnpm install
pnpm dev
```

The development server runs on port 3000 by default. To validate the production build, use `pnpm build`.
